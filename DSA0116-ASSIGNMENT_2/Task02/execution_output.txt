========================================================

Explanation of Compiler Warning [-Wreturn-local-addr]:
1. 'localMark' is created on the activation record (stack frame).
2. When returnLocalVariableReference() returns, the stack frame is deallocated.
3. Returning a reference creates a DANGLING REFERENCE to dead memory.
4. Any dereference in modern C++ (GCC 13) is undefined behaviour and
   causes invalid memory reads, corruption, or trap halts.
5. Compile-time evidence: GCC emits warning: reference to local variable returned!
